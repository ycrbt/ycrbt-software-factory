# ADR-0001: Deterministic orchestration, pluggable roles, Codex-first

**Status:** Accepted for the starter.

Use local Node.js CLI with a deterministic DAG scheduler, dynamically loaded role manifests and a Codex CLI runtime adapter. Only human-created, factory-ready GitHub Issues can be executed. Codex returns structured JSON; changes happen in isolated Git worktrees. No automatic push, merge or deployment.

**Rationale:** Make scheduling reproducible, testable and independent of a specific model or role. LLMs implement frontend tasks, but must not own permissions, product decisions or workflow policy.

**Deferred:** SQLite recovery, retry loops, parallel scheduling, conflict policy, Playwright/visual testing, PR publishing, hardened sandbox isolation, dashboards and budgets.
